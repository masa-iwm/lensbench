# 膜の実測表とモデル

## 膜の実測表（LBCT 形式）

暗号化された膜（.ZEC）は復号せず、OpticStudio の偏光追跡で測った境界の複素 s・p 係数の表を使う。
テキストで、`LBCT 1` の行のあとに `KEY 膜|前の媒質|後の媒質`、`WAVE 波長[µm]`、`入射角[deg] Re s Im s Re p Im p` の行が続く
（詳しくは `lensbench_core::coating::parse_measured`）。ライブラリでは `Coatings::load_measured` で読み、
`System::try_trace_pol` に渡す。

## 膜のモデル（LBCM 形式）

実測表は境界（膜と前後の媒質）ごとに要る。膜のモデルは膜ごとの特性行列（波長・β = n sinθ・偏光ごと）を持ち、
任意の硝材・向き（空気から・硝材から・硝材どうし）・波長（範囲内）・鏡の入射側の媒質で係数を出す。
`LBCM 2` の行のあとに `COAT 名前`、`D`・`BMAX`、`WAVE` と β ごとの行、鏡なら `MIRROR` の節が続く
（詳しくは `lensbench_core::coating::parse_models`）。`--table` と `Coatings::load_file` は 1 行目で LBCT と LBCM を見分ける。
同じ境界に実測表があれば実測表を使う。

モデルは `coat-model` で実測表から作る（`lensbench_core::coat_fit::fit_model`）。表には、屈折率だけのモデルガラス（`"n,0.0"`）を
媒質にした組を入れる: 透過は前の媒質 2 種以上（`AIR`・`1.85,0.0` など）× 後の媒質 2 種以上、鏡は `AIR|MIRROR` と `2.05,0.0|MIRROR`。
波長ごとに特性行列を最小二乗で解き、`D`（OpticStudio の位相の厚さ）と `BMAX` を表から決める。
波長の格子が膜の厚さに比べて粗いと（`coarse`）、波長の間で係数がずれる。必要な格子の目安は `wave_gap_needed`
（波数 1/λ の間隔、係数の差 1e-5 の目安）。膜厚が波長単位（主波長基準）の膜は、主波長で厚さが変わるので、
作ったモデルは測ったときの主波長でしか使えない。
膜の材料の分散表は折れ線で補間されることがあり、その節の波長で係数の波長微分が跳ぶ（折れ目）。折れ目は
`--kinks 0.45,0.5,...` で渡すと LBCM の `KINKS` 行に入り、波長の補間はそこをまたがない（折れ目の波長でも測っておく）。`--kinks` は表にある全部の膜に入るので、材料の違う膜は `--coat` で分けて作る。
折れ目の波長は `lensbench coat-kinks 試しの表.ctab` で探せる（`lensbench_core::coat_fit::detect_kinks`）。空気から入る KEY を、
膜の厚さから決めた格子の 4 倍くらい細かい波長で測った表を渡すと、膜ごとに `--kinks` に渡せる形（`kinks_arg`）を出す。
見逃しうるのは、傾きの跳びが小さい節、数点以内に近接した節、波長の格子が粗い長波長側の節で、鏡より透過の KEY の方が感度が高い
（誤検出は確認した範囲ではない）。膜の材料がわかっていれば、その分散表の節を `--kinks` に足すのが確実。
同じ KEY が複数の表にあれば、`coat-model` は後の表のものを使う（鏡だけ細かい波長で測り直した表を後ろに渡す、など）。モデルガラスの組が足りない膜は飛ばす（`skipped`）。

テキストの LBCM は細かい波長・β の格子で数十〜数百 MB になる。`lensbench coat-compact モデル.lbcm --out モデル.lbcb`
はバイナリ（`LBCM 3`、`parse_models_bin`）に書き直す。値は透過を 1e-9 刻み、鏡の r を 1e-12 刻みの整数にし、
β の方向に 3 階・波長の方向に 2 階の差分を取った残りを、バイトの位ごとに分けて deflate で縮める（テキストの約 1/13〜1/23）。
元の値との差は刻みの半分以下で、係数は変わらない（測定済みの膜で確認）。鏡の刻みを細かくするのは、鏡の補間が |r| の 1 からのずれ
1e-8（`MIRROR_TIR_TOL`）未満を全反射とみて分岐点を探し、分岐点のそばの値が r のわずかな違いに敏感なため。
鏡のモデルは、膜の外の媒質で全反射に変わる点（分岐点）が測った β の点の間にあると、そのそば（β で 2〜3 刻み）では
r が急に変わるのに測った点が足りないので notimpl を返す（分岐点が測った点の上にあれば返さない）。
厚い多層膜では、高い β の導波の共鳴が β の格子（0.00125）より細く、測った点の間に隠れることがある。そこでは
β 方向の有理関数の補間に見かけの極ができ、値が r のわずかな違い（1e-9）で 1e-3 ほど変わる（測定済みの膜で
約 670 万点中 96 点）。分解できていない共鳴なので、その点の値は OpticStudio とも合わない。f32 にしないのは、M̃ の成分が大きい高い β や鏡の分岐点で、丸めだけで 1e-5 近くずれるため。
`Coatings::load_file` は先頭のバイトで LBCM 3 を見分けるので、テキストの LBCM と同じに使える。

透過の位相は既定で OpticStudio と同じ約束にする。その位相には層ごとの項（光線の層の中での横ずれの位相）が含まれ、
β が層の屈折率に近づくと発散するので、モデルは `BMAX` を超える β では止める。`Coatings::phase` を
`PhaseConvention::Physical` にするとこの項を外す（どの β でも有限。OpticStudio とは s・p 共通の位相だけ違う）。
`Physical` は層のわかる膜（膜ファイルの COAT）とモデルにだけ効き、実測表・TABLE には効かない。
膜ファイルの表（TABLE）は OpticStudio と同じく角度を cosθ について線形に補間し、垂直入射（1 − cosθ < 1e-8）では
s にも p の値を使う（表の 0° で s と p が違うと、0° のすぐ外で s に段差が出る）。屈折率の高い側から入る透過（硝材 → 空気の裏面など）は、
表を出る側（屈折率の低い側）の屈折角で引く（OpticStudio と同じ。`tests/filter_os` で照合）。`Coatings::table_normal` を
`TableNormal::Continuous` にすると、0° の行の s を p に置き換えて補間する（段差なし）。

ガラスカタログは `--glass-dir`、環境変数 `LENSBENCH_GLASSCAT`（パス区切りで複数）、.zmx と同じフォルダの順に探す。
