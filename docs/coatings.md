# コーティングの実測表とモデル

## コーティングの実測表（LBCT 形式）

暗号化されたコーティング（.ZEC）は復号せず、OpticStudio の偏光追跡で測った境界の複素 s・p 係数の表を使う。
テキストで、`LBCT 1` の行のあとに `KEY コーティング|前の媒質|後の媒質`、`WAVE 波長[µm]`、`入射角[deg] Re s Im s Re p Im p` の行が続く
（詳しくは `lensbench_core::coating::parse_measured`）。ライブラリでは `Coatings::load_measured` で読み、
`System::try_trace_pol` に渡す。

## コーティングのモデル（LBCM 形式）

実測表は境界（コーティングと前後の媒質）ごとに要る。コーティングのモデルはコーティングごとの特性行列（波長・β = n sinθ・偏光ごと）を持ち、
任意の硝材・向き（空気から・硝材から・硝材どうし）・波長（範囲内）・ミラーの入射側の媒質で係数を出す。
`LBCM 2` の行のあとに `COAT 名前`、（あれば `NOTE 注記`）、`D`・`BMAX`、`WAVE` と β ごとの行、ミラーなら `MIRROR` の節が続く
（詳しくは `lensbench_core::coating::parse_models`）。`--coatings` と `Coatings::load_file` は 1 行目で LBCT と LBCM を見分ける。
同じ境界に実測表があれば実測表を使う。

モデルは `coat-model` で実測表から作る（`lensbench_design::coat_fit::fit_model`）。表には、屈折率だけのモデルガラス（`"n,0.0"`）を
媒質にした組を入れる: 透過は前の媒質 2 種以上（`AIR`・`1.85,0.0` など）× 後の媒質 2 種以上、ミラーは `AIR|MIRROR` と `2.05,0.0|MIRROR`。
波長ごとに特性行列を最小二乗で解き、`D`（OpticStudio の位相の厚み）と `BMAX` を表から決める。
波長の格子がコーティングの厚みに比べて粗いと（`coarse`）、波長の間で係数がずれる。必要な格子の目安は `wave_gap_needed`
（波数 1/λ の間隔、係数の差 1e-5 の目安）。膜厚が波長単位（主波長基準）のコーティングは、主波長で厚みが変わるので、
作ったモデルは測ったときの主波長でしか使えない。
コーティングの材料の分散表は折れ線で補間されることがあり、その節の波長で係数の波長微分が跳ぶ（折れ目）。折れ目は
`--kinks 0.45,0.5,...` で渡すと LBCM の `KINKS` 行に入り、波長の補間はそこをまたがない（折れ目の波長でも測っておく）。`--kinks` は表にある全部のコーティングに入るので、材料の違うコーティングは `--coat` で分けて作る。
折れ目の波長は `lensbench coat-kinks 試しの表.ctab` で探せる（`lensbench_design::coat_fit::detect_kinks`）。空気から入る KEY を、
コーティングの厚みから決めた格子の 4 倍くらい細かい波長で測った表を渡すと、コーティングごとに `--kinks` に渡せる形（`kinks_arg`）を出す。
1 つの折れ目で当たらない候補は、窓の中の 2 つの折れ目でも当て直す（数点の間に並んだ 2 つの節。見つけた折れ目の窓に掛かる候補は見ない）。`--min-score` は候補にする強さの下限（既定 100）。
見逃しうるのは、傾きの跳びが小さい節、3 つ以上が数点以内に近接した節、波長の格子が粗い長波長側の節で、ミラーより透過の KEY の方が感度が高い
（誤検出は確認した範囲ではない）。コーティングの材料がわかっていれば、その分散表の節を `--kinks` に足すのが確実。
同じ KEY が複数の表にあれば、`coat-model` は後の表のものを使う（ミラーだけ細かい波長で測り直した表を後ろに渡す、など）。モデルガラスの組が足りないコーティングは飛ばす（`skipped`）。
`--check 表.ctab`（複数可）は、できたモデル（OpticStudio 互換の位相）を、モデルを作った点とは別に測った表と比べ、コーティングごとの JSON の `check` に
透過とミラーの係数の差の最大（`transmit_max`・`mirror_max`、s・p の大きい方）とその点を出す。差が `--check-tol`
（既定 1e-4）を超えた点（透過と、空気側・硝材側のミラー）を含むモデルの波長の区間の中点（波数で）を `refine_wl_um` に出すので、そこを測り足して作り直せる。
屈折率だけの媒質の KEY だけを見て、後ろの媒質の全反射の近く・モデルの範囲の外（notimpl、`notimpl` に数）は数えない。
硝材側から高い β で入る透過は、層の位相 ψ の折れ目が空気側の KEY よりはっきり出るので、折れ目を探す表にも入れるとよい（`coat-kinks --key`）。

テキストの LBCM は細かい波長・β の格子で数十〜数百 MB になる。`lensbench coat-compact モデル.lbcm --out モデル.lbcb`
はバイナリ（`LBCM 3`、`parse_models_bin`）に書き直す。値は透過を 1e-9 刻み、ミラーの r を 1e-12 刻みの整数にし、
β の方向に 3 階・波長の方向に 2 階の差分を取った残りを、バイトの位ごとに分けて deflate で縮める（テキストの約 1/13〜1/23）。
元の値との差は刻みの半分以下で、係数は変わらない（測定済みのコーティングで確認）。ミラーの刻みを細かくするのは、ミラーの補間が |r| の 1 からのずれ
1e-8（`MIRROR_TIR_TOL`）未満を全反射とみて分岐点を探し、分岐点のそばの値が r のわずかな違いに敏感なため。
ミラーのモデルは、コーティングの外の媒質で全反射に変わる点（分岐点）が測った β の点の間にあると、そのそば（β で 2〜3 刻み）では
r が急に変わるのに測った点が足りないので notimpl を返す（分岐点が測った点の上にあれば返さない）。
補間した分岐点が測った点の上にない波長でも、そのそばは notimpl。補間に使う波長の一部にだけ分岐点があり、ほかの波長では
分岐点が測った β の上端より上にある（層・基板の屈折率が波長で変わって上端を横切る）ところでは、分岐点のある波長の分岐点の手前から
上端までを notimpl にする（波長の補間が分岐点をまたぎ、値が決まらない。硝材側のミラーで OpticStudio と 3e-2 違った）。
分岐点が上端の数点以内にあって分岐点として扱えない波長と、上端のすぐ上（2 刻み以内）に分岐点がある波長も同じに数え、
帯は分岐点の手前の 2 点下からにする（すぐ下も 1e-4 ほどずれるため。上端のすぐ上の分岐点では最後の刻みが 2e-3 ずれた）。
厚い多層膜では、高い β の導波の共鳴が β の格子（0.00125）より細く、測った点の間に隠れることがある。そこでは
β 方向の有理関数の補間に見かけの極ができ、値が r のわずかな違い（1e-9）で 1e-3 ほど変わる（測定済みのコーティングで
約 670 万点中 96 点）。分解できていない共鳴なので、その点の値は OpticStudio とも合わない。f32 にしないのは、M̃ の成分が大きい高い β やミラーの分岐点で、丸めだけで 1e-5 近くずれるため。
`Coatings::load_file` は先頭のバイトで LBCM 3・LBCM 4 を見分けるので、テキストの LBCM と同じに使える。

### 補間の点の数（`ORDER`）と LBCM 4

モデルは補間の点の数を持てる（テキストの `ORDER p`、`CoatModel::order`、p は 4〜12）。持たないモデル（従来）は、
波長を近い 4 点の 1/λ の 3 次式、β を β² の not-a-knot スプラインで補間する。`ORDER p` のモデルは、波長を近い p 点の
1/λ の多項式（折れ目はまたがない）、β を近い p 点の β² の多項式で補間する。層の厚い膜（数十〜数百層）は係数が波長・角度で
細かく揺れ、従来の補間では点が非常に多く要るが、p = 8 なら 1/λ・β² を等間隔にとって、少ない点で済む
（316 層のビームスプリッターで、従来の 4 点では 8000 波長要るところ、8 点なら約 620 波長で係数の差 1e-5）。

厚い膜では、阻止帯や、β が低い屈折率の層を超える所で M̃ の成分が非常に大きくなる（1e12〜1e50 にもなる）。
LBCM 3 は値を 1e-9 刻みの整数（2^60 未満）で持つのでそれが入らない。`coat-compact`・`format_models_bin` は、
`ORDER` を持つモデルか、透過の値が 1e8 を超えるモデルがあれば `LBCM 4` で書く。LBCM 4 は LBCM 3 と同じ並びに、
補間の点の数と、値の塊ごとの変換（大きな値のある透過は asinh にしてから 1e-9 刻み）を足したもの。
元の値との差は max(1, |v|) × 5e-10 以下（大きな値でも相対の差が刻みほど）。それ以外のモデルは今まで通り LBCM 3 で書く。

層のわかる膜から、層を見せずにモデルを作るには `lensbench_core::coating::model_from_layers` を使う
（層の特性行列を格子の点で計算し、`ORDER` とミラーの表も付けられる。ミラーはコーティングファイルのミラーと同じく最後の層を基板とみる）。
コマンドでは `lensbench coat-from-layers COATING.DAT --coat 名前 -o 名前.lbcb` で作る。1/λ・β² に等間隔の格子で計算し、
格子の間の係数の差が `--tol`（既定 1e-5）以下になるまで格子を細かくする（`--max-refine` 回、既定 12 回で届かなければ注意を出し、JSON の `converged` が false。`--wl` 波長の範囲、既定 0.4〜0.7 µm、
`--beta-max` 透過の β の上限、既定 1.4、`--order` 既定 8）。材料はコーティングファイルの MATE だけで、硝材の名前は使えない。
ミラーの表は `--mirror-ref n`（手前の媒質の屈折率）で作る。目安は、12 層の AR で 127 波長 × 46 β・0.3 MB・0.1 秒、
316 層のビームスプリッター（β 1.4 まで）で 921 波長 × 1510 β・27 MB・40 秒。層のわかる膜はコーティングファイルのまま使えば
数 KB で厳密なので、このコマンドは層を見せずに渡したいときのもの。

透過の位相は既定で OpticStudio と同じ約束にする。その位相には層ごとの項（光線の層の中での横ずれの位相）が含まれ、
β が層の屈折率に近づくと発散するので、モデルは `BMAX` を超える β では止める。`Coatings::phase` を
`PhaseConvention::Physical` にするとこの項を外す（どの β でも有限。OpticStudio とは s・p 共通の位相だけ違う）。
`Physical` は層のわかるコーティング（コーティングファイルの COAT）とモデルにだけ効き、実測表・TABLE には効かない。
コーティングファイルの表（TABLE）は OpticStudio と同じく角度を cosθ について線形に補間し、垂直入射（1 − cosθ < 1e-8）では
s にも p の値を使う（表の 0° で s と p が違うと、0° のすぐ外で s に段差が出る）。屈折率の高い側から入る透過（硝材 → 空気の裏面など）は、
表を出る側（屈折率の低い側）の屈折角で引く（OpticStudio と同じ。`tests/filter_os` で照合）。`Coatings::table_normal` を
`TableNormal::Continuous` にすると、0° の行の s を p に置き換えて補間する（段差なし）。

## コーティングファイル（COATING.DAT 形式）の約束

- `MATE` の材料の表は N = n + ik の約束で、吸収は **k < 0** で書く（OpticStudio と同じ）。使う波長で補間した k が
  1e-6 より大きい正ならエラー（増幅する媒質になる。文献の n − ik の k は符号を変えて書く。標準の COATING.DAT にある
  +5e-7 ほどの数値の誤差は止めない）。
- 行が 1 つの材料はどの波長も同じ値。行が 2 つ以上なら、表の中は隣の 2 行の線形、外は近い方の端の行の値
  （外挿しない。OpticStudio と同じで、注意も出さない）。
- `TABLE` の位相（度）は ±180° の折り返しをほどいてから、波長・角度の向きに補間する（+179° と −179° の間を 0° にしない）。

## コーティングの名前で自動で読む

システムのコーティングファイル（.zmx の COFN、Python の `coating_file=`）と同じフォルダに `<コーティングの名前>.lbcb`・`.lbcm`・`.lbct`・`.lbcs` を置くと、
コーティングファイルで決まらないコーティング（暗号化されたコーティングの宣言だけのもの、コーティングファイルにない名前）に、名前の指定なしで使う
（`Coatings::for_system` → `Coatings::load_dir_for`）。`.lbcs` は層のわかる近似のコーティングで、コーティングファイルと同じ形式で
`COAT <コーティングの名前>` の層と、コーティングファイルにない材料の `MATE` を書く（分光の曲線に合わせて作った代わりの多層膜など）。

- コーティングの名前は大文字小文字を区別しない（`X(550nm)` のシステムに `X(550NM).lbcb` を使う）。同じコーティングに複数あれば lbcb・lbcm・lbct・lbcs の順に 1 つ
  （測ったモデル・実測表があれば近似のコーティングより先に使う）。
- システムが使うコーティングのファイルだけ読む（フォルダにある他のコーティングは読まない）。
- コーティングファイルの COAT・TABLE にあるコーティング、理想コーティング（`I.`）、コーティングなしには使わない。
- `--coatings`・`coatings=`・`LENSBENCH_COATINGS` で明示したファイルが勝つ（後から読んで上書きする。自動で読んだ実測表は明示したモデルのあるコーティングから、近似のコーティングは明示したモデル・実測表のあるコーティングから外す）。
- `lensbench coatings システム.zmx --json` の `auto_coatings` に、自動で読んだコーティングとファイルと注記（`note`）が出る。
  モデルの注記は LBCM の `NOTE`（`coat-model --note`、LBCM 3 では末尾の `NOTES`）で、短い測定から作った近似のモデルなどの印に使う。
  `.lbcs` は「近似のコーティング」と出る。境界ごとの `interfaces` にも、注記のあるモデルなら `note` が付く。
- ファイルの中のコーティングの名前がファイル名と違う（大文字小文字を除いて）ときは止める。
- **共有の置き場から取る**: フォルダに目録 `lbcb-remote.json`（`{"version": 1, "files": {"<コーティングの名前>": "<中身の FNV-1a 64 の 16 進>"}}`）
  があれば、フォルダに無いコーティングのモデルを、品の STEP と同じ共有の置き場（docs/project-file.md の「共有の置き場」）の鍵
  `coat/<コーティングの名前>-<ハッシュ>.lbcb` から取り、キャッシュ（品の STEP のキャッシュの隣の `coat`）に置いて使う（CLI・serve・GUI）。
  中身のハッシュを確かめ、作り直したコーティングは別の鍵になる。配る版がリリースの大きさを抑えるためにコーティングのモデルを外すときに使う。
  目録の作成と置き場への上げは `lensbench_cad::coat_remote::upload_dir`（置き場にある鍵は上げない、今の目録にあってフォルダに無いコーティングは目録に残す）、
  目録のコーティングをすべて取ってフォルダに `<コーティング>.lbcb` として置くのは `lensbench_cad::coat_remote::fetch_dir`（Python など置き場を見ない使い方のため）。
  置き場を持つ配る版は、これを呼ぶ保守の道具を自分の exe に足す（公開版の CLI には無い）。

## 分光の曲線から近似のコーティングを作る（coat-design）

暗号化されたコーティングを測れないとき、メーカーの分光の曲線（反射率・透過率）に合う多層膜を当てはめて、近似のコーティング（`.lbcs`）にする。

```
lensbench coat-design curve.csv --name X --materials MGF2,TA2O5 --substrate N-BK7 \
  --coating-file COATING.DAT --glass-dir glass --layers 1..12 --out X.lbcs --json
```

- CSV の列: `wl_um` か `wl_nm`、`angle_deg`（既定 0）、`pol`（`s`・`p`・`avg`、既定 avg）、`quantity`（`R`・`T`、既定 R）、
  `value`（0〜1）か `value_pct`（%）、`weight`（既定 1）。
- 材料は外側（入射側）から繰り返す順。コーティングファイルの MATE か、ガラスカタログのガラス（ガラスなら `.lbcs` に MATE の表も書く）。
  基板は屈折率の数か、材料・ガラスの名前。
- 層の数ごとに、乱数の初期値と、1 つ少ない層の数の最良に層を足したもの・2 つ少ない最良に別の材料の薄い層（針）を挟んだものから
  Levenberg–Marquardt で厚みを合わせる（`lensbench_design::coat_design`）。いちばん合う RMS の (1 + `--slack`) 倍以内で
  層のいちばん少ないものを選ぶ。JSON の `by_layers` に層の数ごとの RMS が出る。
- 同じ曲線を出す設計は一つではない。合わせた曲線の外（位相、別の角度、別の基板、硝材の側から入るとき）は元のコーティングと違いうる。
  斜めの曲線（45° の s・p など）があれば足すと外れが減る。

ガラスカタログは `--glass-dir`、環境変数 `LENSBENCH_GLASSCAT`（パス区切りで複数）、exe の隣の `catalogs/glass`（あれば）、.zmx と同じフォルダの順に探す。
