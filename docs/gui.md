# 使い方（GUI）

画面はすべて、CI で GUI を自動で操作して撮ったもの（`lensbench-gui --tour`、下の「画面の通し確認」）で、main の最新の画面です。

## 起動

```
cargo build --release -p lensbench-gui      # target/release/lensbench-gui(.exe) の 1 ファイルだけで動く
lensbench-gui system.zmx                    # 引数・窓へのドロップ・「ファイル > 開く」で系を開く
```

Windows の exe は CI（windows-latest）の成果物 `lensbench-gui-windows` からも取れる。

*examples/projects/P8_catalog_two.json を開いたところ。左が系のパネル、右が解析のパネル（スポット・MTF・波面）*

## 画面の並び

- パネル（系・カタログ・解析）はタブを引きずって並べ替え・分割・フロートでき、タブの右クリックで別の窓（別モニター）に出せる。
  同じ解析を何枚でも開ける。「並び」メニューに初期の並び（解析中心・カタログと組合せ・2 画面）と、名前を付けて保存した並び

## 系のパネルと値の変更

- 系のパネル: 焦点距離・F 値・NA・全長などと、見るパラメータ（名前は Python・serve と同じ `3.t`・`G1.shift` など）。
  値を変えると「自動」の解析をすぐ計算し直し、前の値との差（スポットの RMS の差・MTF の前の曲線）を出す

## 解析

- 解析のパネル: CLI の解析（spot・mtf・wavefront・rms・psf・elements・ghost など）。図で見られるのは、スポット図（視野ごとの光線の点と Airy 円）、
  回折・幾何 MTF の曲線、波面図（色）と干渉縞（参照球との干渉、倍率・傾きの縞を選べる）、回折 PSF（色、対数も）、Zernike 係数の棒、
  フィールド MTF・スルーフォーカス MTF・RMS（視野・フォーカス・波長）の曲線、2 光束の干渉縞（fringe）の図（量・構成は
  設定の欄で、CLI と同じ）、簡易 POP（pop、面・距離・方法は設定の欄で。省くと像面まで伝えられる最後の面から像面まで）の照度の図と
  x・y の断面。光線の表（rays、面ごとの交点・方向・光路長）と膜の境界（coatings、面ごとの膜・前後の媒質・扱いと、実測表が要る境界）は表で見る。この GUI を組み込んだ exe は解析・図・設定の欄を足せる（`lensbench_gui::ext`）。
  ほかは表で見る。CLI の引数は「追加の引数」に JSON で（serve の `analyze` と同じ）。周波数を省いたフィールド・スルーフォーカス MTF は遮断周波数の 1/10・1/4・1/2

## カタログ

- カタログのパネル: ガラス（nd・νd で絞り込み、ガラスマップ）とカタログレンズ（型番・メーカー・ガラスの検索、焦点距離・径の範囲、
  正負、枚数、種類（レンズ・鏡・BS）、列で並べ替え）を探す。選んだレンズは断面（平行光が集まる様子）を見られる。レンズの行をダブルクリック（レイアウト図で選んでいる要素の直後に入る）か、組合せのレイアウト図へドラッグ（落とした位置に差し込む）で「組合せ」に足し、反転・間隔・入射瞳径・視野・波長を決めて
  「この組合せで系を作る」でプロジェクトファイル（ブロック）にして開く
- 未完の品（カタログに厚さ・径の無い品、「⚠ 未完」の印）は置けない。ダブルクリックか「品ページから補う…」で補う窓が開き、
  品ページを 1 件だけ開く（Windows はアプリ内のブラウザ（WebView2）、ほかは既定のブラウザ）。アプリ内のブラウザでは仕様表
  （`Thickness (mm):` など）を読んで欄に入れ、CAD 欄から STEP を落とせば測って入れる（仕様表と食い違えば知らせる。枠付きの品では STEP の厚さ・径は枠を含む外形で、ガラスの厚さ・径にならない）。既定のブラウザ
  のときは、ページの文字を写して貼り付けるか、落とした STEP を選ぶ。値を確かめて確定すると、設定のフォルダの `catalog-fill` に
  保存し、次からは普通の品として並ぶ。ボットの判定・captcha はページのまま見せる（回避しない）
- Windows では、未完の品の行を選んで 1.5 秒そのままにすると、その品のページだけを見えない窓で開いて仕様表を読み、厚さ・径が
  一通りに決まればそのまま補って保存する（矢印キーで流しても続けて開かないよう、次を開くまで 5 秒空け、同じ品は起動の間に 1 度だけ）。
  欄が無い・値が食い違う・ボットの判定や captcha のときは、20 秒後にその窓を見せて補う窓に引き継ぐ
  タイミングはサイトごとに設定のフォルダの `catalog-fill-timing.json` で変えられる（起動時に読む。書かない項目は既定）:
  `{"default": {"dwell_s": 1.5, "gap_s": 5, "wait_s": 20}, "sites": {"edmundoptics.com": {"gap_s": 15}}}`。
  `dwell_s` は行に止まってから開くまで、`gap_s` は同じサイトで前に開いてから次を開くまで、`wait_s` は窓を見せるまで（秒）。
  サイトはホスト名で、そのサブドメインにも当たる。読めないファイルは状態の行に誤りを出し、既定の値で動く

## 組合せ（カタログレンズを並べて系を作る）

- レイアウト図の「光線・書き出しの設定」: 描く視野・波長、光線の並び（y・x・十字・格子・周）と本数、描く面の範囲、色分け
  （視野・波長・構成）と、書き出しの PNG の横幅・分割数・3D の光線の管の半径（CLI の `layout` と同じ。設定は次に開いたときも使う）。
- 組合せのパネル: 組合せのレイアウト図（玉の断面・光線・像面）。カタログの玉のほか、自作の玉・平板・鏡・絞り・
  開口・遮蔽（円・矩形・楕円の開口、円の遮蔽、スパイダー（腕の幅・本数）。内側・外側の半径と偏心）・ビームスプリッター・.zmx の玉を足せる。
  自作の玉は「＋ 面」で面を足して貼り合わせ・3 枚玉に、「面の並び」は空気中の面（Jones 行列の面・座標ブレーク・平面）、
  「.zmx の取り込み」は .zmx の面の範囲をまるごと（測定系の中の被検レンズなど。.zmx の絞りを使うか選べる）。玉は「前面を絞りに」でき、
  .zmx の玉・取り込みは構成番号を選べる。系の設定で硝材カタログ（AGF、前ほど優先）を選ぶ。系の設定の「膜（フィルタ）の定義」でロングパス・ショートパス・バンドパス・ノッチ・ND・波長ごとの透過・表の膜を名前を付けて定義でき（プロジェクトの `coatings`、透過の曲線を 0°・45° で見る）、鏡・BS の膜の欄の ▾ から選ぶか、面の表の膜（coating）に名前を書いて使う。要素をクリックで選び、横にドラッグで光軸に沿って動かす（Shift で偏心）。
  寸法の数字をクリックすると、その場で書き換えられる（今の数字は全選択。Enter で決める、Esc でやめる。終えた後も ← → が効く）。
  寸法線（数字の外）のクリックは選ぶだけで、下にスライダーが出て ← → で動かせる（選んで Enter でも書き換え）。
  要素はロックでき（L キー）、ロックした要素は動かせず設定も変えられない。キーは [ ] で選ぶ、← → で動かす、↑ ↓ で偏心、
  Shift+↑ ↓ で傾き、R で反転、F で BS の反射を逆向きに、Delete で外す。光軸が斜めのときは、光軸に近い向きの矢印（← → か ↑ ↓）で光軸に沿って動き、寸法は光軸に平行に出る。「変えたらすぐ作り直す」で動かすたびに系を作り直し、開いている解析も
  計算し直す（前との差が出る）。動かしている間はレイアウト図を先に描き直し、解析は止まってから回す。「像面を近軸の焦点へ」で最後の空気を軸上の細い光線が軸と交わる所までにする。
  要素の設定に ON/OFF（OFF の要素は系に入らない。OFF は詰めるか同じ長さの空気で残すか）がある。上の「状態」で状態（プロジェクトの `states`）を足して選ぶと、ON/OFF・後の空気・偏心・傾き（寸法・要素の設定・ドラッグ・矢印キー）と BS の経路は
  その状態の値を変え、系はその状態で作る（測定系の出し入れ・ズーム。「基本の値に」「基本の経路に」で状態の値をやめる）。
  系の設定のパネルで「状態 … だけの値にする」を選ぶと、開口・視野・波長・物体距離・テレセントリック・エイミング・アフォーカルも
  その状態だけ変えられる（プロジェクトの状態の `project`。絞りの位置・硝材カタログは全部の状態で共通）
  要素の設定の「群」で続く要素に同じ名前を付けると群（プロジェクトの `group`）になり、上の「群」で役割（ズーム・フォーカス・固定）と移動を決める
  （状態を選んでいれば、その状態の移動）。.zmx の取り込みでは「玉の群」で面 from〜to をまとめて玉の境を手で直す（`groups`）

## 干渉計を組む

- 組合せで干渉計を組む: BS の要素の設定で形（キューブ・平板・理想の面）、平板の厚さ・くさび・裏で分ける、分ける面の傾き、分け方
  （分岐比・膜・理想の PBS の Tp・Ts）、ほかの面の膜（`ar`）・面ごとの膜（キューブ a〜d、平板の表・裏）を変えられる（カタログの BS の中身もここに出る）。
  「口の先に並べる（分岐）」で口 B（透過）・C（反射）・D（B から戻る光の反射）の先にそれぞれ要素を並べられ（BS は並びの最後、後ろの要素は今の口の先へ移る）、
  鏡の「往路を戻る」で腕の端にする（Twyman-Green・Michelson など）。図・解析は上の「経路」（BS を通る順の T・R、プロジェクトの `path`）の 1 本で、
  ほかの経路は「重ねる構成」の BS の経路で重ねて描ける。図の要素の番号・選択・ドラッグ・寸法は今の経路に沿った並び

## レンズデータ

- レンズデータのパネル: 系の面を OpticStudio の Lens Data のような表で見て、セルをダブルクリック（または ← → ↑ ↓ で選んで Enter・F2）
  で書き換える（コメント・曲率半径・厚さ・硝材・膜・半径・コーニック。曲率半径の空・inf は平面）。ブロック（玉・群）は OpticStudio の Black Box の
  ように 1 行にたたみ（その行の厚さはブロックの後の間隔）、クリックで選ぶ（組合せではレイアウト図の選択と連動）、ダブルクリック・Enter でそのブロックに入って
  中のブロックと面だけを見る（Backspace・マウスの戻るボタン・上の「系 › …」で戻る）。ブロックの行を選ぶと表の下にブロックの設定が出る（組合せは要素の設定と同じ値を偏心 x・y・傾き x・y・z まで、開いた系は玉・群の偏心・傾き・移動・dn・disp を serve の `set` で）。表の下に選んだ面の設定があり、面のすべての項目（種類・絞り・無視・非球面係数・
  座標ブレーク・Jones・dn・disp・開口・前後の傾き偏心・面タイプの形のデータ、ソルブ・ピックアップ、「全項目（JSON）」）を変えられる。組合せのレイアウト図で要素をダブルクリックしても、その要素の面が出る。ブロックはロックでき（L キー）、
  ロックしたブロックと中の面は変えられない（組合せでは要素のロックと同じ）。開いた系は serve の `edit` で変え、「系ファイルに保存…」で保存する。
  組合せの系では、要素の最後の面の厚さは後の空気、ほかの値は要素の面の上書き（プロジェクトの `surface_edits`）として組合せに残る（絞り・ソルブ・ピックアップは要素の面の `surface_ops` に残る。絞りを外すと前の絞り・絞りの要素に戻る）
- 開いた系では、ブロックの設定の上で玉・群の名前・面の範囲を変えたり外したりでき（範囲を変える・外すのは動き・移動が 0 のとき）、
  表の下の「玉・群・機構部品」で、面の範囲を書いて玉・群（ズーム群・フォーカス群など）を足し、機構部品（置く面・ずれ・傾き・寸法・穴）を
  置く・変える・消す（serve の `edit` の `define_unit`・`set_unit`・`remove_unit`・`add_mech`・`set_mech`・`remove_mech`）。
  面の設定の「複屈折」で、複屈折材の板の入口（mode・結晶軸）・出口を付ける（入口の面の後の材料が常光、材料名-E が異常光）。

## 系の設定・多重構成

- 系の設定のパネル（開いた系）: 名前・開口（種類・値・テレセントリック）・エイミング・アフォーカル・視野（種類・正規化・視野の表を足す・消す）・
  波長（重み・主波長、足す・消す）・環境（温度・気圧・屈折率を合わせる）・GLRS・ROPD・膜ファイルを変える（serve の `system_data`・`set_system_data`）。
  レンズデータの「＋ 面」・Insert キーで選んだ行の前に面を足し、「− 面」・Delete キーで選んだ面を消す（OBJ・IMA・ブロックの行・ロックした面は消さない）
- 多重構成のパネル: OpticStudio の Multi-Configuration Editor のような表（行 = パラメータ `3.t`・`2.c`・`G1.shift` など、列 = 構成）。
  セルのクリックで値を書き換え、構成の番号のクリックでその構成の値を系に入れる（解析・図・面の表が追従）。＋ − で構成を足す・消す、名前を入れて行を足す、✖ で行を消す。
  .zmx の多重構成は「表に取り込む」で表にする（構成で違う値を行に。硝材など表にできない違いは注意に出す）。面の表・パラメータで値を変えると今の構成の列も変わる。
  表は系ファイルに保存される。組合せの系の構成はプロジェクトの状態で扱う

## 最適化

- 最適化のパネル: 変数（`7.t`・`lens2.tx` など。「候補から足す」で面・玉・群から選ぶ。範囲・効く構成）、評価関数（既定の
  RMS スポット・波面と、項の表: spot・wavefront・mtf・paraxial・ray・opd・zernike・coupling・zplm・plugin。CLI の `--term` と同じキー・重み・構成）、
  設定（反復の上限・微分・同時に扱う構成）を決めて「最適化する」。走っている間は評価関数の履歴が出て「止める」で止められる。結果は
  評価関数の履歴・変数と項の前後の値で、「系に反映」で開いている系（組合せなら面の厚さ・曲率半径・コーニックを組合せの要素）に当て、
  「反映を元に戻す」で戻す。設定は serve の `optimize` と同じ JSON で保存・読込できる

## 差し替え探索

- 差し替え探索のパネル: 差し替える玉（組合せのカタログの玉か、プロジェクトの id のある玉のブロック）ごとに候補を
  メーカー・焦点距離・径で絞り（「裏返しも」で向きを両方）、組ごとに最適化する間隔（組合せは `d0`（絞りの後）・`d1`（1 つ目の要素の後）…、
  プロジェクトは id のある空気 `gap.t` や `G2.shift`）と設定（評価関数・反復・焦点距離の目標・組の上限・有効径の条件 `clear_aperture`・微分 `jac`・粗いふるい）を決めて「探索する」。
  「評価関数に足す項」は最適化と同じ欄（`terms`）、「出発点・状態」では出発点（`starts`、1 行に 1 つ「d1.t=10, d2.t=5」）と、
  同時に評価する状態（`states`）・状態ごとに解く変数（`state_vars`）を選べる。
  「組の数を数える」で回す前に組の数と候補を確かめられ、走っている間は進み具合が出て「止める」で止められる。結果は評価関数の小さい順の表で、
  組合せなら「入れる」でその組（玉と間隔）を組合せに入れ、「入れる前に戻す」で戻せる。設定は `lensbench swap --spec` と同じ JSON で保存・読込

## 公差

- 公差のパネル: 玉の公差の組（一般・精密・高精度・なし）とカタログの玉のメーカーの公差、分布、玉ごとの組・群の公差・面ごとの公差、
  補償子（最適化と同じ欄）、評価関数（最適化と同じ欄）、試行の数・種を決めて「公差を回す」。
  「メーカーごとのカタログの玉の公差」で `catalog_tols`（メーカーごとの組か項目の値、外径・|焦点距離|・貼り合わせかの条件つきの上書き）を、
  「設定」で出す百分位（`percentiles`）・スレッド数（`threads`、自動は 0）・試行ごとの値を結果に入れるか（`samples`）を決める。走っている間は進み具合が出て「止める」で止められる。
  結果は評価関数と項の統計（公称・平均・標準偏差・百分位）、累積分布の図、補償子の動き、寄与の大きい項目（感度、悪い順）、試行との相関。
  設定は `lensbench tolerance --spec` と同じ JSON で保存・読込

  解くパラメータ（群の移動 `G2.shift`・間隔 `7.t` など、範囲も）を決めて「軌跡を解く」。間の点の数・像の評価・基準・反復の上限も選べる。
  結果は位置・状態・目標・焦点距離・変数・像の評価の表と、変数の軌跡の図（[ズーム軌跡](zoom.md)）。

## キーボード・表示・設定

- 下の行に状態と EFFL・F/#・NA・全長・像高、版（git のハッシュ。クリックでコピー）
- キーボードだけで操作できる: Ctrl+K コマンドパレット（操作・解析・パネル・並びを名前で探す）、Ctrl+N 新規（組合せを空にする）、Ctrl+O 開く、F5 計算、
  Ctrl+R 読み直す、Ctrl+Tab 次のパネル、F1 キーの一覧
- 「表示」で配色（暗い・明るい・OS に合わせる）とアクセント色、言語（日本語・英語、既定は OS の言語）。
  画面の文字列は `crates/lensbench-gui/lang/`（言語を足すときは表を足す）
- 「ファイル > カタログのフォルダ」でガラス（.AGF）とレンズ（.zmx のフォルダ）の場所を決める。設定と並びは次に開いたときも使う
- 設定の保存先: 既定は OS の場所（Windows `%APPDATA%\lensbench\data\app.ron`、Linux `~/.local/share/lensbench/app.ron`）。
  exe の隣に `lensbench.portable`（空のファイル）か `settings.ron` があればポータブルで、exe の隣の `settings.ron` に保存し、
  exe のフォルダの中のカタログのフォルダ・最近のファイル・組合せの .zmx は相対パス（区切り `/`）で書く（フォルダごと移しても使える）。
  初めてのポータブルの起動で OS の場所に設定があれば取り込む。フォルダに書けなければ OS の場所に保存する。`--settings FILE` で
  ファイルを決めることもできる（相対パスはそのファイルのフォルダから）。硝材・レンズのフォルダが空なら、exe の隣の
  `catalogs/glass`（硝材）・`catalogs/lens`・`catalogs/items`（レンズ）を既定に使う
- 日本語のフォントは OS のもの（Windows は游ゴシック・メイリオ・MS ゴシックの順）を起動時に読む。`LENSBENCH_GUI_FONT` で選べる。
  字の縦位置はフォントの寸法から真ん中に揃える（`LENSBENCH_GUI_FONT_Y` で手で決められる。字の大きさに対する割合、正で下へ）
