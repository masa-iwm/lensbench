# ゴースト（2 回反射）

`lensbench ghost` は面 a で反射し面 b（b < a）で反射する経路（OpticStudio の Ghost Focus Generator の double bounce）を
全部の組について並べる: 像面での近軸の周辺光線の高さ（ぼけの半径）・角度、像面から近軸のゴーストの焦点までの距離、
作動 F 値と、軸上の主光線の強度の比（ゴースト / 元の系、膜の反射率・透過率・吸収込み、x・y の偏光の平均）。
`--first`・`--last` で反射させる面を絞り、`--out-dir` で展開した系を `ghost_a_b.zmx` に書く。

経路は順次の面の列に展開した系（`lensbench_core::ghost::ghost_system`、Python は `s.ghost(a, b)`）なので、追跡・偏光・
MTF などはそのまま使える。逆にたどる区間は元の面の写し（共軸なら厚さの符号を変えるだけ、傾き・座標ブレークがあれば
元の面の位置へ移す座標ブレークを挟む）で、面の位置は元の系と大域の座標で一致する。反射する面の偏光の係数は、入射側と
反対側の境界（膜込み）の反射 r（鏡と同じ約束。膜の向きは透過と同じ規則、位相は基板の面を頂点に置いた値）。暗号化された膜は
特性行列モデル（LBCM）から求める（透過の実測表だけでは求められない）。像面は膜があるとき先の反射面になる
（検出器の反射は像面に理想膜 `I.xx` などを付けて表す）。

OpticStudio 2026 R1.01 との照合（tests/ghost）: ゴーストのオペランド GPRX・GPRY（像面での実光線）が A0・F0 の全組で
5e-12 mm、近軸の周辺光線の高さ GPSY が 6e-14 で一致。膜の反射率・位相は Coatings の Reflection vs Angle と R 5e-8・
位相 5e-5° で一致（位相の基準面の違いはテストの注記）。合わないもの: 傾き・偏心のある系（C0）で、反射の間に傾いた面をはさむ
組。OpticStudio の保存するゴーストの系（GH*.ZMX）は戻りの経路で傾いた面の傾きを落としている（C0 の GH004003 の面 3）ので合わせない（2026-11-08 決定）。また OpticStudio のゴーストの
透過率 GPRT は反射面を膜なしの鏡（アルミ 0.7 − 7i）として計算し、面の膜の反射率を使わない。
