# 非順次の追跡

順次のシステム・プロジェクトから作った物の場面（`lensbench_project::scene::Scene`。レンズは前面・後面・縁で閉じた立体、ミラー・絞り・
機構部品・検出器）の上で、光線が次に当たる面を面の番号ではなく交点の距離で決めて追う（`lensbench_project::nsc`）。
境界ごとに反射と透過へ分かれ、検出器のパワー（インコヒーレントに足す）と、光線が通った出来事の列（経路）ごとのパワーの表
（OpticStudio の Path Analysis に当たる）を出す。ゴースト（[2 回反射](ghost.md)）を 3 回以上の反射・縁・機構部品まで
広げたものに当たる。

## 使い方

- CLI: `lensbench nsc system.zmx`（`--json`・`--save` で結果を書く）。プロジェクト（.json）は光束（`beams`）ごと、光束が無ければ BS の
  経路ごとのシステムの物を 1 つの場面に置く
- GUI: 解析の一覧の「干渉・伝搬」の「非順次の追跡」。収支の行、検出器ごとの照度の図（既定は対数。ピークから 6 桁）、経路の表を出す。
  表の行をクリックするとその経路だけの照度を出す。「レイアウト図に重ねる」で、光源の光線の一部（`layout_rays`、図では既定 100 本）の
  検出された枝をレイアウト図（2D・3D）に重ねる。色は経路の表の行ごと（灰色は表に無い経路）、薄いほどパワーが小さい。反射の回数で
  絞るか、表の行を選んでその経路だけを描く（展開した図には描かない）
- Python: `System.analyze_file(path, "nsc", glass_dirs=..., grid=31)`（読み込んだ 1 つのシステムなら `s.analyze("nsc")`）
- serve: `analyze` の `nsc`

設定（CLI の旗は `_` を `-` に）:

| 設定 | 既定 | 意味 |
|---|---|---|
| `field` | 全視野 | 光源の視野の番号（1 始まり） |
| `wave` | 主波長 | 波長の番号 |
| `grid` | 21 | 視野ごとの瞳の光線のグリッドの一辺 |
| `power` | 1 | 光源の全体のパワー [W] |
| `polarization` | `unpolarized` | 光源の偏光（`unpolarized`・`x`・`y`。物体の座標系） |
| `split` | `deterministic` | 分け方（`deterministic`・`monte-carlo`） |
| `seed` | 1 | 乱数シード（モンテカルロ） |
| `threshold` | 1e-6 | 枝を捨てる（ロシアンルーレットにかける）パワーの割合 |
| `max_events` | 256 | 1 本の光線のイベントの数の上限 |
| `half` | 像面の半径 | 検出器の矩形の半幅 [mm]（x, y。1 つなら正方形） |
| `pixels` | 64 | 検出器の一辺の画素の数 |
| `reflections` | すべて | 検出器の像に数える経路の反射の回数（1 つか、最小と最大）。経路の表と収支は全部 |
| `paths` | 20 | 経路の表の行数（パワーの大きい順） |
| `layout_rays` | 0 | レイアウト図に描くために追い直す光源の光線の数（等しい間隔で選ぶ。0 で描かない。5,000 本まで） |
| `sequential` | false | 経路の表の行ごとに、その経路を持つ順次のシステムを探す（下の `sequential`） |
| `out` | | 行のゴーストのシステムを .zmx で書くフォルダ（`sequential` と一緒に。`ghost_a_b.zmx`、場面のシステムが複数なら `ghost_k_a_b.zmx`） |
| `coatings` | | 測ったコーティングの表（LBCT）・モデル（LBCM） |

結果: `budget`（`source_w`・`detected_w`・`absorbed_w`・`escaped_w`・`discarded_w`・`truncated_w`・`residual_w`）、`detectors`
（`label`・`half_mm`・`nx`・`ny`・`pixel_mm2`・`power_w`・`peak_w_mm2`・画素の中心 `x`・`y`・`irradiance` [W/mm²]（番号 j·nx + i、j は +y の向き）・
`hits`）、`paths`（`rank`・`detector`・`reflections`・`power_w`・`fraction`・`rays`・`events`。`events` は「面の名前 種類」を ` > ` でつないだもの。
種類は T 透過・R 反射（ミラーも）・TIR 全反射・D 検出。`pixels` はその経路だけの照度の [画素の番号, W/mm²] の並びで、0 の画素は省く。
反射の回数の絞り込みに依らない。`sequential` はその経路の順次のシステム（設定 `sequential` のときだけ）: `kind` が `system`（場面のシステム `name` の
主の経路）・`ghost`（システム `system` の面 `a`・`b`（b < a）で反射する[ゴースト](ghost.md)。`file` は書いた .zmx）・`beam`（プロジェクトに足すと
この経路になる光束: BS の経路 `path`（null は既定の経路）とレンズの面で折り返す `turn`）・`none`（`reason`。散乱する経路、レンズの面での反射が
3 回以上の経路など））、`path_count`、`rays`（`layout_rays` 本の光源の光線の検出された枝: `path` 経路の表の順位（表に無ければ 0）・
`reflections`・`power_w`・`pts` 光源の始点と出来事の点 [x, y, z] mm（大域、レイアウト図と同じ座標）。上限 5,000 本）、`warnings`

## 約束

- 交点: 全部の面のうち最も近いもの。面の境界の箱の木（BVH、平らな配列）で絞る。順次の面の形は基準の二次曲面の根と
  頂点の平面を初期値にニュートン法で詰める
- 境界: 屈折・反射・全反射。分かれ方はコーティング込みの Fresnel で、係数は偏光追跡と同じ（透過は `coat|入射側|反対側`、反射は
  `coat|入射側|反対側|R`、ミラーは `coat|入射側|MIRROR`。[コーティング](coatings.md)）
- 偏光: 光線ごとにグローバル座標の電場のベクトルを持ち、|E|² を光線のパワー [W] とする。偏光なしの光源は直交する 2 つの状態に
  半分ずつ
- 媒質: 硝材の内部透過率（カタログの IT）で通った長さの分を吸収する
- 光源のパワー: 全パワー P [W]（既定 1 W）を光線に分ける。検出器の照度は W/mm²
- 分け方:
  - 決まった分岐（既定）: R と T の両方を追い、パワーが光源の光線 1 本の閾値倍（既定 1e-6）より小さい枝を捨てる
  - モンテカルロ: R か T をパワーの比の確率で選ぶ（パワーは両方の和のまま。コーティングのある検出器の反射と検出も同じ）。閾値より小さくなった光線は半分の確率で
    2 倍にして残す（ロシアンルーレット）。乱数は光線の番号と出来事の回数から決まる
- 物ごとの働き: レンズの面・縁は境界、空気中のミラーは両側で反射（残りは吸収）、空気中の絞りは開口の外が遮る有限の板（外径は絞りの面の固定した機械半径、無ければシステムの面の半直径・機械半径の最大。その外を通る光、たとえば BS のほかの腕は遮らない）、機構部品の壁は
  吸収、検出器（像面）は矩形の中に順次のシステムの光が来る側から当たったパワーを画素に数える（像面にコーティングがあれば反射の分は先へ
  進む）。裏から来た光は検出器を素通りする（検出器は物の陰を作らない）
- 結果はスレッド数に依らない（光線を決まった数ずつの組に分けて組ごとに数え、組の順に足す）
- エネルギーの収支: 光源 = 検出 + 吸収 + 外へ出た + 閾値で捨てた + 出来事の数の上限で止めた。決まった分岐では丸めの誤差の範囲で閉じる。モンテカルロはロシアンルーレットで残した（2 倍にした）分が収支の外なので、平均でだけ閉じる（`residual_w` は 0 にならない）
- 扱わない面（誤り）: 理想レンズ・Jones 面・回折（Binary 2）・Fresnel 面・複屈折材・利用者定義の面。散乱は後の段

## 照合

- 内部（tests/nsc.rs）: 2 回反射の枝が展開したゴーストのシステム（`ghost_system`）と A0・F0 の全組で位置 1e-9 mm・パワー 1e-9（相対）、
  反射 1 回の枝が光束の turn と、BS の経路の枝が tests/splitter の各経路のシステムと同じ許容で一致。エネルギーの収支は 1e-12。
  モンテカルロは決まった分岐と画素ごとに 3σ 以内、スレッド数 1・4 で同じ値
- OpticStudio 2026 R1.01 の非順次（Convert to NSC Group、光源は同じ光線の Source File、偏光と Split NSC Rays、閾値 1e-6）と A0・F0 で
  照合した。系の条件を揃えると（Standard Lens の Clear を順次の半直径に、縁を円柱に、絞りの板を十分大きく）、検出の全パワーの差は
  1e-12 W 以下、吸収・外へ出た分・捨てた分の差も 1e-12 以下、経路の数（A0 667・F0 670）と上位 60 経路の並び・光線の本数が同じで、
  パワーの相対差は上位 20 経路で 6e-12 以下。硝材の内部透過率のあるカタログでも、検出の差 3e-9 W、経路の相対差 2e-8 以下
- 変換したままの OpticStudio のモデルとは、Convert to NSC Group が Clear を順次の半直径の 1.0001 倍にし、縁が Clear と機械半径の
  大きい方になる（前後で違うと円錐になる）ので、上位の経路で 1e-3 ほど、縁で全反射する経路では数 % 違う

## 速さ

A0（レンズ 3 枚、面 14）、軸上の視野の瞳のグリッド 101（偏光なしで 15,690 本）、Linux の 4 スレッド（クラウドの作業機）:

| 分け方 | 1 スレッド | 4 スレッド | 経路の数 |
|---|---|---|---|
| 決まった分岐（閾値 1e-6） | 2,500 本/秒 | 8,900 本/秒 | 603 |
| モンテカルロ | 22 万本/秒 | 46 万本/秒 | 21 |

決まった分岐は、コーティングの無い面の反射 4 % で 4 回反射（2.6e-6）までの枝を追うので、光源の光線 1 本あたり数百の枝に
なる。面の多いシステム・光線の多い照度の図はモンテカルロが向く。
