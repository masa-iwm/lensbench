# パラメータの名前

最適化の変数・公差・光路長の微分・ピックアップ・多重構成の表の行は、パラメータを `面.種類` の名前で指す
（Python の `get_param`・`set_param`・`grad=`、serve の `params`・編集の操作、CLI・プロジェクトの `param` の欄。Rust は
`lensbench_core::param::Kind::parse`）。種類の名前は大文字・小文字を問わない。

## 指し方

- **面のパラメータ**: `3.t`（面 3 の厚み）、`L1 front.c`（面の名前（コメント）.種類）。面の番号は OpticStudio の面番号（物体面が 0）。
- **玉・群のパラメータ**: `lens2.tx`（玉モードの 2 番目の玉）、`G1.shift`（群 G1）。名前が面の名前と玉・群の名前の両方にあるときは
  `unit:名前.種類`・`surf:名前.種類` で分ける。
- **システムの値**: 面の番号を付けない（`objx`・`wave1`・`aper` など）。
- 視野・波長の番号は 1 から（`fx1`・`wave1`）。

## 面のパラメータ

「変数」は最適化の変数と光路長の微分（`grad=`）に使えるもの。「多重構成」は多重構成の表の行にできるもの（右の列は .zmx の多重構成の
オペランド。読むときも書くときもこの名前）。「ピックアップ」はピックアップの元と先にできる量。

| 名前 | 意味 | 変数 | 多重構成（.zmx） | ピックアップ |
|---|---|---|---|---|
| `c`（`curv`） | 曲率 [1/mm] | ○ | `CRVT` | ○ |
| `r`（`radius`） | 曲率半径 [mm]（0 は平面） | ○ | | ○ |
| `k`（`conic`） | 円錐係数 | ○ | `CONN` | ○ |
| `a2`〜`a16` | 偶数次非球面の r²〜r¹⁶ の係数 | ○ | `PRAM`（面タイプのパラメータの番号） | `p1`〜 で |
| `z1`〜`z231` | Zernike Sag の面の項 j の係数 | ○ | `PRAM` | `p1`〜 で |
| `t`（`thick`） | 次の面までの厚み（面 0 は物体距離） | ○ | `THIC` | ○ |
| `dx` `dy` `tx` `ty` `tz` | 座標ブレークならその値、ほかの面は面の前の傾き偏心（傾きは度） | ○ | 座標ブレークは `PRAM` | `p1`〜・`before0`〜 で |
| `dn` | 面の後の媒質の屈折率に全波長で足すずれ | ○ | | ○ |
| `disp` | 同じ媒質の分散の相対変化（n = n0(λ) + dn + disp·(n0(λ) − n0(主波長))） | ○ | | ○ |
| `u_<項目>` | 利用者定義の形の面の設定の数の項目（[ライブラリ](rust.md)） | ○ | | |
| `semi` | 半直径（多重構成では固定の半直径。浮動開口の面はその半直径でける） | | `SDIA` | ○ |
| `ignore` | 面を無視するか（0・1） | | `IGNR`（面の範囲の `IGNM` も読む） | |
| `apmax`・`apmin` | 円形の開口・遮蔽の最大・最小の半径 | | `APMX`・`APMN` | |
| `apdx`・`apdy` | 開口・遮蔽の偏心 | | `APDX`・`APDY` | |
| `aptype` | 開口の種類（OpticStudio の番号。表で変えられるのは 0 なし・1 円形の開口・2 円形の遮蔽の間） | | `APTP` | |
| `before0`〜`before4` | 面の前の傾き偏心の値（dx dy tx ty tz の順） | | `CBDX`〜`CBTZ` | ○ |
| `after0`〜`after4` | 面の後の傾き偏心の値 | | `CADX`〜`CATZ` | ○ |
| `beforeorder`・`afterorder` | 面の前・後の傾き偏心の順序（0 偏心から、1 傾きから） | | `CBOR`・`CAOR` | |
| `nd`・`vd`・`dpgf` | モデルガラスの nd・vd・ΔPgF（面の材料がモデルガラスのときだけ） | | `MIND`・`MABB`・`MDPG` | |
| `tce` | 面の熱膨張係数 [1e-6/°C] | | `TCEX` | |
| `mech` | 面の玉の半径 [mm]（読むと自動の値も、設定すると固定の機械半径。自動より小さい値は使わない。多重構成の行を置くと全部の構成で固定になり、値を書いていない構成は今の玉の半径の値） | | `MCSD` | |
| `chip` | 面のチップゾーン [mm] | | `CHZN` | |
| `material` | 面の材料（値は構成ごとの材料の名前） | | `GLSS` | |
| `coating`（`coat`） | 面のコーティング（値は構成ごとのコーティングの名前、空はコーティングなし） | | `COTN` | ○ |
| `csp1`・`csp2` | 曲率のソルブ（ピックアップを含む）の条件の値 | | `CSP1`・`CSP2` | |
| `tsp1`〜`tsp3` | 厚みのソルブ（ピックアップを含む）の条件の値 | | `TSP1`〜`TSP3` | |
| `psp1_n`〜`psp3_n` | 面タイプのパラメータ n のピックアップの値 | | `PSP1`〜`PSP3` | |
| `p1`〜（`parm1`〜） | 面タイプのパラメータ（.zmx の PARM の番号） | | | ○ |

- ソルブの条件の値の番号は OpticStudio のソルブの窓の順（周辺光線の高さは高さ・瞳の帯、F ナンバーは F ナンバー、ピックアップは元の面・倍率・オフセット）。
  ソルブもピックアップも無い面の行は効かない。
- `p1`〜 はピックアップ・マクロのソルブだけの量で、パラメータとしては `a4`・`dx` など意味のある名前で指す。
- 材料・コーティングの行は数でなく名前を持つ（Rust の `set_config_materials`・`set_config_coatings`、編集の操作の `set_config_materials`・
  `set_config_coatings`、Python の `set_config_names`・`config_names`）。コーティングの名前の空はコーティングなし。

## システムの値

面に付かないパラメータ。最適化の変数・微分には使えない（`objx`・`objy` を除く）。公差・多重構成の表の行に使う。

| 名前 | 意味 | 多重構成（.zmx） |
|---|---|---|
| `objx`・`objy` | 有限物体の物点の x・y [mm]（追跡の入力で、システムのデータではない。光路長の微分にだけ使う） | |
| `wave1`〜 | 波長 [µm]（変えると全媒質の屈折率がその波長の値になる） | `WAVE` |
| `wwt1`〜 | 波長のウェイト | `WLWT` |
| `primary` | 主波長の番号（1 から） | `PRWV` |
| `aper` | 開口の値（開口の種類の単位: 入射瞳径 mm・F 値・NA など） | `APER` |
| `atype` | 開口の種類（OpticStudio の番号 0〜5: 入射瞳径・像側 F 値・物体側 NA・絞り径・近軸作動 F 値・物体側の開き角） | `SATP` |
| `stop` | 絞りの面の番号 | `STPS` |
| `ftype` | 視野の種類（OpticStudio の番号 0〜3: 角度・物体高・近軸像高・実像高） | `FLTP`（4 の経緯儀の角度は角度として読む） |
| `fx1`〜・`fy1`〜・`fwt1`〜 | 視野の x・y・ウェイト | `XFIE`・`YFIE`・`FLWT` |
| `vdx1`〜・`vdy1`〜・`vcx1`〜・`vcy1`〜・`van1`〜 | 視野のけられ係数 | `FVDX`・`FVDY`・`FVCX`・`FVCY`・`FTAN`（`FVAN` も読む） |
| `temp`・`pres` | システムの温度 [°C]・気圧 [atm]（変えると全媒質の屈折率を作り直す） | `TEMP`・`PRES` |
| `afocal` | アフォーカルの像空間か（0・1） | `AFOC` |
| `apodtype`・`apod` | アポダイゼーションの種類（0〜2: 一様・ガウス・cos³）とガウスの係数 | `APDT`・`APDF` |
| `aiming` | 光線エイミング（0〜2: なし・近軸・実光線） | `RAAM` |
| `ropd` | OPD の基準（0〜3、.zmx の ROPD と同じ） | `OPDR` |

## 玉・群のパラメータ

`名前.種類` で、種類は `dx` `dy` `tx` `ty` `tz`（剛体としての偏心・傾き。回転の中心 pivot のまわり）・`shift`（光軸に沿った移動）・
`dn`・`disp`（中の媒質）。最適化の変数・公差・微分に使える。玉は読込で `lens1`・`lens2` …（玉モードの番号）、群は Python の
`define_unit`、プロジェクトではブロック・群の `id`。

## 使えない所

- `set_param`・公差には、物点（`objx`・`objy`）・名前の値（`material`・`coating`）・`p1`〜 を除いて使える。
- ピックアップの先になったパラメータは変えられない（元の面を変える）。ソルブで決まる曲率・厚みも変えられない。
- 名前が違えば、誤りの文に使える名前の一覧が出る。
