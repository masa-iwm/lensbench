# モンテカルロ公差

- `tolerance`: 公差（パラメータのずれの範囲と分布）で系をずらし、補償子（`compensators`、ピント `9.t`・群の位置 `G1.shift` など）を
  評価関数で減衰最小二乗により合わせ直して（反復 `comp_iters`、既定 10）、評価関数の分布（統計・百分位・昇順の値 `cdf`）・
  項ごとの分布・補償子の分布を出す。多重構成では補償子に `configs`（構成の番号の並び）を書くとその構成だけに効き、構成ごとに
  1 つずつ書けば構成ごとに別の値で合わせる（ズーム群の位置など。省くと全構成で同じ値）。
  `"radial": true` で、偏心・傾き・くさびの x・y を組にして円の中で一様に引く（大きさが公差以下。x・y 別々では角で √2 倍まで）。
  `"radial": "normal"`（`"normal:3"` で σ の数）なら、組を等方の 2 次元正規分布（σ = 公差 / σの数、既定 2）で引いて半径（公差）の外は
  引き直す。2 次元では半径 2σ の中は 86%・3σ で 98.9%（1 次元の 95%・99.7% と違う）。公差ごとには `disc_x:normal`・`disc_y:normal` の組。
  設定は JSON（`--spec` のファイルと `--set` の上書き。キーの一覧は `lensbench_project::tolerance`）。
- 簡易設定: 玉ごと（玉モードの玉。名前はブロックの id か lens1 …）に公差の組 `preset`（`commercial` 一般・`precision` 精密・
  `high` 高精度）を当てる。組は曲率半径（比、面ごと）・中心厚・くさび（後ろの面の傾き）・屈折率・分散（アッベ数の比）・
  玉の偏心・傾き・後の空気の間隔。`lenses` で玉ごとに上書き（項目ごと、組の名前、null で公差なし）、`groups` で群・ブロックの
  偏心・傾き・移動（玉 1 つのブロックでは玉の偏心・傾きとは別に足す組立の公差。名前は「G1 群の偏心x」など）。プロジェクトのレンズカタログの玉は、カタログの玉の公差（中心厚 ±0.1 mm・焦点距離 ±2%・芯取り 5′。焦点距離は玉の曲率半径を
  すべて同じ比で変える）を既定にし、`catalog_tols` でメーカーごとの公表値（外径・焦点距離で変わる規則 `rules` も書ける。
  `lensbench_project::tolerance::catalog_rule`）を与える。
- 鏡の `back` で同じ玉を往復する系（ダブルパス）では、往きと戻りの範囲を 1 つの玉（名前はブロックの id）として、同じ誤差を
  両方に与える（曲率・くさびは同じ面に同じだけ、厚さ・間隔は戻りで逆の符号、屈折率・分散は同じ媒質、偏心・傾きはブロックの動き）。
  面の番号は往きの順なので、逆向きに置いた玉は R1・R2 が玉の後ろの面から数えた番号になる。
- 詳細設定: `tols` に面ごとの公差（`{"param": "3.t", "pm": 0.05}`、複数のパラメータを同じ乱数で `{"params": [...]}`、
  比なら `"relative": true`、範囲 `lo`・`hi`、分布 `dist`、パラメータごとにずれに掛ける数 `scale`（例 `[1, -1]`））。分布は `uniform`・`normal`（範囲の端が ±2σ、`normal:3` で ±3σ）・
  `end`（端の値を半々）。
- 評価関数は最適化と同じ（`merit`: `wavefront` 既定・`spot`、`terms` で MTF・近軸量などの項。Python では関数の項も使えるので
  計測を模した値なども評価量にできる）。公称の評価も補償子を合わせた後の値。
- 感度（`sensitivity`、既定 true）: 公差ごとにその公差だけを lo・hi にした評価関数の変化を、悪い順に出す（寄与の大きい項目）。
  `rss_estimate` は公称 + √Σ 変化²。`correlation` はモンテカルロの試行から、評価関数とずれ（`r`）・|ずれ|（`r_abs`）の相関。
- 試行は並列に回し（`--threads`）、試行ごとの乱数は種 `seed` と試行の番号だけで決まるので、スレッド数によらず同じ結果になる。
  `--save-worst` で最も悪い試行の系（補償の後）を書き出す（.json は系ファイル。屈折率のずれは .zmx に書けない）。
- Python は `System.tolerance(spec, terms=None, vendors=None, configs=None)`、serve は `tolerance`。複数の構成では
  同じずれをすべての構成に与える。
