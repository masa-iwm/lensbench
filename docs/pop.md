# 簡易 POP（回折の伝搬）

`lensbench pop` は、実光線を面 `--surf`（省略で、間に平面のダミー面だけを挟んで像面まで伝えられる最後の面。`--dist`・`--to` も省けば像面まで伝える。そういう面が無ければ、次の面まで伝えられる最後の面から次の面まで）まで追跡して、その面の接平面の上に複素振幅の場を作り（振幅は光線の密度、
位相は光路長。面の開口、絞り面なら絞り半径の円を格子の上で掛ける。遮蔽・スパイダーのように外の縁の無い開口では、
光の外の縁は瞳の縁（絞り面なら絞りの円）のまま）、一様な媒質の中を `--dist`（省略で次の面の
頂点面まで）伝えた照度を出す。往路で絞りを通った光が復路の絞り面に落とす影、ピントずれと絞りの縁の影響を見る用途。
パワーは正規化瞳の単位円の中で 1（照度は W/mm²）。

- 場は傾きと曲率の「パイロット」の波面を除いた残りを格子に持つ（集光する場でも収差・ピントずれだけを標本化）。
- 方法（`--method`）: `fresnel`（Fresnel 近似の積分。出力の格子は自由）、`angular`（角スペクトル、FFT。近い距離。
  パイロットに曲率があればその球面に沿った座標で）、`direct`（Rayleigh-Sommerfeld の積分。近似なし、遅い）。
  既定の `auto` は、Fresnel の積分の核が標本化できる距離なら Fresnel（Fresnel 近似で落とす位相が 0.01 rad を
  超えて重すぎなければ direct）、近ければ角スペクトル。
- 出力の `kernel_step`（核の位相の標本の間の差、π を超えると折り返し）と `fresnel_error`（Fresnel 近似で落とす
  位相の目安）で標本化と近似を確かめる。f/5 程度より速い集光は Fresnel 近似が効かないので direct を使う。
- 照合: 円形・正方形の開口（Fresnel 積分、Rayleigh-Sommerfeld の閉じた式）、集光の Airy 像と軸上のデフォーカス、
  Gauss ビーム、実レンズの Strehl 比（OPD から）と一致する（`crates/lensbench-core/tests/pop.rs`）。
  OpticStudio 26.1.1 の POP とも照合（`tests/pop_refs`、`tests/pop_os.rs`）。OpticStudio の POP は近軸で伝えるので、
  f/25 のピントずれで +3%、f/5 の焦点で近軸の値（+0.85%）、f/5 のピントずれでは 10〜40% 近似なしの値から離れる。
